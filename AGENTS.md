# Repository Operating Guide

This repository is the zero-browser-extension CLI/MCP product extracted from `qiuzhaozhushou`.

Before coding, read `feature_list.json`, `progress.md`, and the README for the module you will change. Keep one feature in progress at a time. Run `npm run validate` before marking it done and record changed files, commands, evidence, blockers, and the next feature in `progress.md`.

Personal information stays local. Never store recruitment passwords or authentication cookies, bypass CAPTCHA/SMS/identity checks, or click final submission. MCP exposes intent-level tools only; it must not expose raw CDP, selectors, scripts, scalar profile values, arbitrary uploads, or arbitrary page actions.

Real-site claims require the retained real page and an independently frozen field denominator. Fixtures and object tests prove only protocol or primitive behavior.
