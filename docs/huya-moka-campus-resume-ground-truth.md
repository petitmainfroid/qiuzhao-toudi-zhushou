# 虎牙直播 Moka 校招“我的简历”Ground Truth

## 归类与范围

- 公司：**虎牙直播**。
- ATS 家族：**Moka**，家族标识 `moka`。
- 归类：`shared-ats-tenant`，不是虎牙自建招聘系统。
- 公共租户：`https://app.mokahr.com/campus_apply/huya/:siteId`。
- 简历路由：`#/candidateHome/resume`。
- 页面类型：Moka 校招候选人标准简历编辑器。
- 证据日期：2026-08-07。

归一化文件按家族和公司保存：

`ats-corpus/ground-truth/moka/huya/huya__campus-candidate-resume__v1.json`

虎牙公开租户页面直接声明组织 id 为 `huya`、显示名称为“虎牙直播”、模式为 `campus`，并在页脚标明“Moka，智能化招聘管理系统”。因此这个页面应归入 Moka 家族，而不是为虎牙创建一个独立 ATS 家族。

## 独立验收基准

未登录的页面不会返回候选人简历值。当前 GT 由两部分独立公开证据组成：

1. 虎牙 Moka 租户的公开 HTML 壳确认公司、租户、校招模式、语言和在线简历开关。
2. 同一页面引用的公开 Moka `applyWeb` 代码包声明候选人简历页复制 `DEFAULT_APPLY_SETTING`，随后删除 `uploadInfo` 分组，并通过标准表单组件呈现剩余字段。

因此当前基准是 **9 个分组 / 41 个逻辑字段 / 1 个默认必填字段 / 6 个可重复分组 / 7 个选项字段 / 0 个附件字段**。

| 分组 | 可重复 | 字段数 | 公开代码选中的字段 |
| --- | --- | ---: | --- |
| 个人信息 | 否 | 10 | 姓名、手机号码、邮箱、性别、出生日期、工作经验、最高学历、所在地、最近公司、证件号码 |
| 求职意向 | 否 | 3 | 当前薪资、期望薪资、期望城市 |
| 工作经历 | 是 | 5 | 开始时间、结束时间、公司名称、职位名称、工作职责 |
| 教育背景 | 是 | 5 | 开始时间、结束时间、学校名称、专业名称、学历 |
| 实习经历 | 是 | 5 | 开始时间、结束时间、公司名称、职位名称、工作职责 |
| 项目经验 | 是 | 6 | 开始时间、结束时间、项目名称、职务、项目描述、项目中职责 |
| 语言能力 | 是 | 4 | 语言类型、掌握程度、听说、读写 |
| 自我描述 | 否 | 1 | 自我描述 |
| 获奖经历 | 是 | 2 | 获奖时间、奖项名称 |

公开默认配置只把“姓名”标为必填。这是代码配置事实，不代表虎牙实际投递某个职位时只有姓名必填；职位申请表可以使用另一套租户/职位级申请表配置。

固定选项包括：

- 性别：男、女；
- 学历：本科、硕士、博士、高中、大专、中专、MBA、其他；
- 语言熟练度：一般、良好、熟练、精通；
- 工作经验：1–40 年，以及在校生、应届毕业生、1 年以下。

“证件号码”被标记为身份敏感字段，后续适配器必须要求用户确认。虽然 Moka 的公共字段全集包含简历、附件和照片上传能力，但这个“我的简历”组件明确删除了 `uploadInfo`，所以本页 GT 的附件字段数为 0，不能把申请页附件入口算进来。

## 只读在线审计

运行：

```powershell
npm run audit:huya-moka
```

审计只执行公开 GET 请求：两步取得虎牙租户 HTML 壳，再读取壳中当前引用的 Moka `applyWeb` 静态代码包。首次请求产生的匿名引导 Cookie 只在该进程内用于取得公开 HTML，不会写入文件或 GT。

审计验证：

- 虎牙直播、`huya`、校招模式与租户配置；
- `/candidateHome/:page` 和 `/candidateHome/resume` 路由；
- 标准简历复制默认配置并删除上传分组的行为；
- 9 个分组的顺序、41 个字段的技术名/中文标签/类型；
- 唯一默认必填字段、6 个可重复分组和四套选项目录；
- 候选人资料读取边界 `/api/outer/ats-apply/personal-center/candidateInfo`；
- 简历保存边界 `PUT /personal-center/resumeInfo`。

最后两个接口只作为公开代码中的边界字符串检查，审计不会调用它们。

## 证据边界与下一步

这是“虎牙租户身份 + Moka 标准简历代码”的 **public-shell-and-bundle-contract**，不是登录后真实 DOM，也没有读取候选人 API 响应。它不能证明控件包装、日期弹窗、选项弹层、动态增删、校验提示或实际填写已经适配成功，也不能单独证明其他 Moka 公司使用完全相同的版本和配置。

下一步应由开发者本人登录虎牙校招页面，在侧边栏主动导出匿名结构，与 **9 组 / 41 字段**逐项核对。采集不得包含姓名、手机号、邮箱、证件号码、已有输入值、文件名、Cookie、令牌或请求正文；不得触发验证码、保存或最终投递。
