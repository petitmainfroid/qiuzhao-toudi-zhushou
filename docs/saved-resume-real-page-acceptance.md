# 常用简历 PDF：真实招聘网页验收标准

## 产品目标

用户在秋招助手中选择一次 PDF，关闭页面或重启浏览器后仍可复用。招聘网页必须先通过确定性规则识别唯一简历控件；真正把文件交给网站前仍显示 PDF、HTTPS Origin 和目标控件并由用户确认。确认可能触发网站立即上传，但扩展永远不点击最终投递。

## 证据等级

证据不得混用，低等级不能替代高等级：

1. **L0 真实公开契约**：实时职位/表单接口仍包含简历附件字段；只证明站点契约存在。
2. **L1 登录真实页只读结构**：绑定用户已登录标签页，只输出 Origin、脱敏路径、文件控件数量、accept tokens、非个人结构类别、候选数量和 submit 数量。不读取 input 值、文件名、Cookie、token 或页面个人文本。
3. **L2 安装扩展预检**：用户在准确标签页点击扩展图标；扫描显示一份本机已保存 PDF、准确 Origin 和唯一目标，确认前网页/网络不变。不得从本地 fixture 推断这一等级通过。
4. **L3 用户确认的真实附件**：用户核对真实 PDF 和目的地后亲自确认。页面只接受一次预期附件；若控件 `change` 即上传，只允许一条对应附件请求。身份/其他附件和最终提交均保持不变。
5. **L4 后续页面免选文件复用**：在同一浏览器配置中关闭并重开扩展或进入另一招聘申请页，不打开系统文件选择器即可再次到达 L2；每次站点传输仍遵守产品确认策略。
6. **R 稳定本地回归**：合成 PDF 和 ATS 结构固定候选发现、授权、字节传输、删除与 zero-submit。它适合 CI，但不能证明 L1–L4。

## L1 可执行只读审计

先由用户在 Chrome 中打开并登录目标申请页，再绑定当前标签页：

```powershell
opencli browser qiuzhao-live bind
npm run audit:resume-attachment-live -- `
  --session qiuzhao-live `
  --expected-origin https://xiaomi.jobs.f.mioffice.cn `
  --expected-path-prefix /internship/resume/
```

通过条件：

- 页面是批准的 HTTPS Origin 和路径前缀；输出只保留数字 ID 脱敏后的路径形态与 query key 名；
- 恰好一个安全简历候选，接受 PDF、非 multiple、未 disabled；
- 包装层存在简历信号，且不存在身份证、证件、护照、照片、成绩单、作品集、推荐信或资格证信号；
- 输出的所有安全计数保持 false：不读值/文件名/Cookie，不改 DOM，不上传，不提交。

## L2 安装扩展预检

1. 使用当前 `dist/` 重载秋招助手；权限仍只有 `activeTab`、`scripting`、`sidePanel`、`storage`。
2. 在目标招聘标签页亲自点击秋招助手图标，再点击扫描。
3. 侧栏必须显示已保存 PDF 的私密信息、准确 HTTPS Origin 和唯一简历控件；没有再次打开文件选择器。
4. 在点击附件确认前，不应发生附件请求；页面现有附件和 submit 状态保持不变。
5. 候选为 0、候选超过 1、目标变化、已有本地文件、PDF 损坏或权限失效时停止。

真实文件名和摘要只供用户在本机核对，不写入测试输出、截图、Git 或进度日志。

## L3 真实附件门禁

只有用户明确批准“这份真实 PDF + 这个精确 HTTPS Origin”后才执行：

- 记录浏览器/扩展版本、脱敏路径、候选数、accept tokens、确认/result 状态码、附件请求形态与状态类别；
- 不记录真实文件名、摘要、字节、档案/页面值、Cookie、授权头或响应正文；
- 附件目标恰好一个，页面接受或返回有界服务器拒绝；授权无论成功失败都只能消费一次；
- 不改变身份证、照片、成绩单、作品集、证明、密码、验证码、隐私同意或删除控件；
- submit click 与最终申请请求必须为 0。

不得使用 OpenCLI `browser upload` 代替秋招助手：它绕过本地 PDF 仓库、候选发现和一次性授权，不能作为产品通过证据。不得用合成身份或简历污染真实招聘系统。

## 当前小米真实页反例

2026-08-06 的登录只读结构显示：页面只有一个文件 input，接受 PDF，但 input 本身没有 label、name、id、ARIA、placeholder 或 `data-form-field-name`。简历语义只存在于最近的 `.atsx-upload-btn`/`.atsx-upload-drag` 包装层。旧的 `nearbyText` 只看 form item/group/section heading，得到空上下文，因此不会产生简历候选。F035 用匿名结构回归修复这一缺口；L3 仍需安装扩展和用户确认，不能由结构观察代替。
