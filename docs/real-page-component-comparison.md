# M019 真实招聘页面：区块优先识别、填写与截图核验

> 日期：2026-08-16。范围是用户已登录且保留的真实页面。结构读取使用 CDP 与区块优先模块；截图只由 `page-vision` 作为独立验收证据。本文不保存字段值、DOM、选择器、Cookie、证件号码或截图文件。所有页面均未执行保存、同意、删除、验证或最终提交。

## 判定口径

- 冻结分母沿用接入前同一真实页面的逻辑字段清单：小米 45、虎牙 54、蔚来 33、MetaApp 34。小米另有 54 个原始控件，聚合单选组、日期范围和保护组件后成为 45 个逻辑字段。
- “已识别”表示组件有明确区块、记录序号、字段语义以及可填写/保护/只读终态，不等于一定有本地资料或允许自动填写。
- 填写成功必须同时满足受控执行器的 Boolean 回读和同一页面截图核验。最后一次幂等复跑没有可执行动作，表示已填字段未被再次误写；缺少资料和失败关闭项仍保留为明确终态。
- 页面位置均按截图自上而下记录，截图捕获在核验后清理。

## 携程

保留页是 `/experienced/jobList` 职位列表，只观察到 3 个普通页面控件和 0 个申请表语义；它不是可填写申请页。因此未创建字段分母、未授权、未填写。需要用户打开实际申请/简历编辑页后，才能按同一流程冻结分母并验收。

## 结论

区块优先模块已进入正式读取链：`page-readiness -> CDP 结构读取 -> sectionKind/recordIndex -> planner -> 安全编译 -> 受控填写与 Boolean 回读 -> page-vision 截图核验 -> 审计`。四个真实申请页不存在仍未分类的可见组件；剩余空白由本地资料缺失、受保护策略或真实下拉候选歧义导致。视觉模块仍只用于验收，不参与用户日常填写决策。
