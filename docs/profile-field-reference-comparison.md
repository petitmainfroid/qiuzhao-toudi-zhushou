# 个人信息页字段对照

核对日期：2026-08-07
公开参考：https://offerlink.tech/myResume

本文件只记录公开页面暴露的字段名称和本项目的产品取舍。没有复制参考站源码、样式、接口、用户数据或实现代码。

## 已有覆盖

- 基本信息：姓名、英文名、性别、出生日期、手机、邮箱、国籍、当前城市、籍贯、政治面貌。
- 经历：教育、实习、项目、作品、获奖、语言能力。
- 求职与长文本：目标岗位、意向城市、到岗日期、自我介绍、自我评价、个人优势、职业规划。
- 文件：一份本机常用 PDF，招聘网站附加前仍需确认。

## 本次补齐

- 基本信息：民族、婚姻状况、宗教信仰、身高、体重、家庭/学校所在城市与区县、兴趣爱好、紧急联系人。
- 教育：学院、专业分类、主要课程、专业描述。
- 实习：行业、工作地点、实习成果。
- 项目：项目中职责。
- 获奖：奖项类别、级别、等级。
- 语言：考试或证书、听说能力、读写能力、成绩。
- 求职偏好：期望行业、期望/当前薪资、岗位调剂、内推、招聘信息来源、工作经验。
- 新增重复章节：在校职务、校园活动、家庭成员、证书、论文期刊、专利。

## 明确不支持

- 密码、短信/邮件验证码、CAPTCHA、Cookie 和登录凭据：不读取、不保存、不填写。
- 获奖证明、证件、成绩单等通用附件：不自动上传。
- 最终申请提交：产品没有对应动作。

## 安全分级

- 身份证、护照等证件类型和号码可以进入本地档案，并可从明确标注的本地简历中提取；当前版本尚未加密，编辑器和填写预览会遮罩号码，每次写入招聘网页仍需确认。
- 家庭成员、紧急联系人、民族、婚姻、宗教、身高体重和家庭所在地属于确认必需字段，不参与默认安全填写。
- 家庭成员数据涉及第三方隐私，页面明确提示应先取得本人同意。
- 其余字段仍由确定性字段目录匹配；未识别、冲突或低置信度字段保持不选中。
